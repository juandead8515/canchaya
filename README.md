# CanchaYa

Plataforma web para consultar disponibilidad y reservar canchas deportivas en línea.

## Integrantes
- Juan Castelblanco

## Estado actual (Fase II)
Prototipo funcional de front-end con:
- Navegación entre pantallas (Inicio, Canchas, Reservar, Mis reservas)
- Formulario de reserva con validaciones básicas
- Verificación de horarios ocupados
- Almacenamiento de reservas en el navegador (localStorage)
- Cancelación de reservas

Pendiente para la entrega final: integración del servicio de Inteligencia Artificial (asistente virtual para reservar).

## Tecnologías
- HTML5, CSS3, JavaScript (sin frameworks)

canchaya/

1. Clona el repositorio.
2. Abre `frontend/index.html` en el navegador.
